# Word-Part Hoops and clearer start page — November 8, 2026

Implemented Word-Part Hoops, an optional five-round basketball game using each existing reward's cumulative eligible morpheme pool across Flights A, B and C. It reads the registry's displayed meanings and labels, excludes duplicate labels and overlapping meaning tokens within a question, and uses only eligible content. It does not introduce token requirements or write instructional progress. Every unlocked reward offers Shoot hoops in My Games; the practice setup now has a visible My Games button. Locked sets remain locked.

A learner picks a ball by meaning, adjusts horizontal aim, and shoots along an animated arc. A wrong meaning gives the selected part's meaning and a retry; a correct meaning with a missed shot explicitly preserves correctness and offers another aim attempt. Line up shot is optional assistance; Harder shots narrows the basket tolerance and varies starting aim. No question timer. Keyboard range controls, touch controls, Escape, focus containment/restoration, and reduced-motion animation supported. Points exist only for the game session.

Start page: educator planning links moved into a disclosure; learner / word-part / activity steps are ordered. Existing Flight and Stretch controls retained in a collapsed Adjust practice disclosure.
