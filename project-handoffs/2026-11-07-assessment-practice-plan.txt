Morphology assessment-to-practice handoff — November 7, 2026 Eastern

Implemented
- All three assessment report pages offer Choose practice from these results. Report items/scores remain available for educator review; no automatic score cutoffs or placement.
- Educator confirms a shared learner, Practice Flight, word-part category/combination, activity and Standard/Stretch choice. An existing plan is loaded first. A local assessment profile is preselected only when its UUID matches an eligible shared learner. No new learner is created from the report.
- The main educator workspace can set, change or clear the plan. Save success requires a confirmed backend response. A stale or uncertain save requires reloading the latest revision. Open practice with this learner applies the saved choices for educator-selected/shared-screen use.
- Student sees Start today’s practice and Change practice. Starting applies the plan; Change practice reveals flexible activity choices without changing the plan. No saved plan preserves the prior choose/continue path. Returning to an unchanged plan does not interrupt the open activity. Updated plans are checked on open/return, not pushed in real time.
- Plans persist until educator changes/clears them. They select the existing Flight/category/activity pools, not an individual word-part filter or a locked sequence.
- Quick Start Guide updated, including saving scope and limits. Phone assessment item-detail overflow contained so the page and plan form fit 390 px.

Storage and access
- Separate private morphology_practice_plans table: canonical student/owner IDs, four enum/boolean practice choices, revision, active flag and timestamp. No assessment responses, Student Code, free-text notes or assessment score uploaded.
- Direct anon/authenticated table access denied; RLS enabled. Public entry points require authenticated execution plus server-checked current session, canonical ownership or student link, active class/product access and current learner permission. Students can read only their own plan and cannot save/clear any plan.
- Existing student progress saves cannot overwrite the separate teacher plan. Optimistic revision checks reject stale writes.
- Migration applied to staging and production. No student release, anonymous Auth, parent-permission release or existing entitlement settings enabled. Both plan tables empty after tests.
