Adaptive recommendation

Recommended Session

First Volo chooses the next target and activity from the student's recent performance. This remains the student's adaptive recommendation unless new performance is actually saved.

Educator choice

Teacher-Selected Session

You choose the word part and activity for a specific instructional reason. Opening this session does not rewrite the student's recommended next target. If performance from this session is later saved, record its source as Teacher selected.
