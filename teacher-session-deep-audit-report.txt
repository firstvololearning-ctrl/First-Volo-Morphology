ROOT-CAUSE SUMMARY
- The page currently has multiple rendering layers: old session UI, ready-to-use UI, runtime DOM repair layers V7-V13, and separate printable markup.
- Several V9-V13 fixes are post-render text/visibility patches rather than changes to the source session model.
- The Teacher Session Plan rewrite assumes ordered-list numbers are in li.textContent, so stale counts survive.
- The Step 5 variation finder omits h3, so the live question headings can escape V12; V13's 5-item limit then escapes too.
- Step 4 and Step 5 are not truly progression-gated.
- Part A application words are shown in the same pre-response prompt, cueing the target form.
- Print has its own markup path, so screen fixes do not automatically propagate.
